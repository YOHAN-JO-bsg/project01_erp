# 웹 기반 치킨프랜차이즈 소상공인 ERP 시스템 개발

> 매출 정산, 발주·입고 물류, 근태 관리를 하나로 통합하여 가맹점 운영 효율과 본사의 데이터 의사결정을 지원하는 웹 ERP 시스템

<br>

* **개발 기간:**  2025.07.23 - 2025.08.12
* **개발 인원:** 총 10명 (기능 단위 Full-Stack 협업 방식)
  
<br>

## 기술 스택 (Tech Stack)

| 구분 | 기술 |
| :-- | :-- |
| **Backend** | Java Servlet, JSP, Tomcat |
| **Frontend** | JavaScript, HTML5, CSS3, Bootstrap, TOAST UI |
| **DB & Infra** | Oracle DB (JDBC) |
| **협업툴** | Git, GitHub, Notion |

<br>

## 담당 영역 : 지점별 매출 통계 풀스택 개발

* JSP와 순수 JDBC 기반의 지점별 매출 데이터 분석 대시보드 전담 개발
* SQL 집계 쿼리를 활용한 주간·월간·연간 총 매출액 및 평균 매출액 산출 로직 구현
* 기간별 주간·월간·연간 매출 순위 및 최고/최저 매출일 분석 기능 개발
* 날짜 필터, 통계 항목 선택 등 조건 분기 처리 및 실시간 데이터 조회 기능 구현
* 대량의 매출 트랜잭션 처리를 위한 SQL 쿼리 최적화 및 페이징 처리 구현
* JSP 기반 화면 구성 및 통계 데이터 시각화 테이블 렌더링 구현
